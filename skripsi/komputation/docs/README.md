## Urutan membaca

1. **[`DESAIN_EKSPERIMEN.md`](DESAIN_EKSPERIMEN.md)** — apa yang diukur dan
   kenapa: dua sumbu eksperimen, hipotesis, definisi sel, aturan pengambilan
   sampel berpasangan. **Baca ini dulu.**
2. **[`HASIL_TAHAP0.md`](HASIL_TAHAP0.md)** — angka Tahap 0 yang mendasari
   rancangan: probe realignment, kapasitas kanal simbolik, rumus tiap mode
   (§9) dan bukti kesetiaannya terhadap kode rujukan (§9.2).
3. **[`PANDUAN.md`](PANDUAN.md)** — panduan operasional: setup RunPod, data,
   model, menjalankan kedua lengan, VRAM terukur, dan masalah yang sering
   muncul.
